# Glossary

Domain jargon, acronyms, and project-specific terms. Kept in sync with `docs/domain/`.

---

| Term | Definition |
|------|-----------|
| A/B Test | Controlled experiment comparing two or more page/experience variants to determine which performs better against a defined metric |
| ADR  | Architectural Decision Record — a short doc capturing a significant design choice and its rationale |
| CCPA | California Consumer Privacy Act — US data privacy regulation |
| CRO | Conversion Rate Optimization — the practice of increasing the percentage of users who complete a desired action |
| DXO | Digital Experience Optimization — broader discipline encompassing testing, personalization, and behavioral analytics |
| docs/ | Source-of-truth folder; human-written authoritative documentation |
| GDPR | General Data Protection Regulation — EU data privacy regulation |
| KPI | Key Performance Indicator — measurable value used to track progress toward a goal |
| Multivariate Testing | Experiment testing multiple variables simultaneously to find the best-performing combination |
| RBAC | Role-Based Access Control — permission model where access is granted based on a user's role |
| SmartStats | VWO's Bayesian statistical engine used to determine winning test variants with high confidence |
| Split URL Testing | A/B test variant where different URLs serve different experiences (vs. same-URL DOM changes) |
| wiki/ | AI-generated summaries derived from `docs/`; never the primary source |
